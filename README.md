# ATAMap

Atatürk'ün 1881-1938 hayatı; mektup, telgraf, konuşma ve seyahatleri dönem sınırlarıyla çizilmiş tek ekranlık bir harita üzerinde. Kişisel, ticari olmayan bir proje.

## Çalıştırma

```
npm install
npm run dev     # geliştirme sunucusu
npm run check   # typecheck, lint, test, derleme, boyut bütçesi
```

Node 24 gerekir. Yayın: Vercel Hobby (`vercel.json`).
